# plc/codesys

Native CODESYS project file (`.project`) for the SmartSort Line PLC.

- Contains the full PLC application: POUs (Ladder + Structured Text), GVLs, task configuration and the Modbus TCP / OPC UA server setup.
- Binary format — open it in CODESYS V3.5. For a readable version of the code see [`../export/`](../export/).
